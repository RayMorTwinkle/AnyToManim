# AnyToManim — draft architecture

## Design principles

1. **Audio-first.** In a 3b1b video the narration *drives* the visuals, never the reverse.
   The pipeline therefore synthesizes speech before finalizing animation timing.
2. **Code is the truth.** Everything downstream of the storyboard is executable, diffable,
   and re-renderable — the "code-centric" thesis Code2Video validated, extended to audio.
3. **Agent-native.** Every stage is a small deterministic-ish tool call an agent can run,
   inspect, and retry in isolation. No monolithic "press button, get video".
4. **Critic everywhere.** Each artifact (outline, storyboard, code, frames, sync, final cut)
   has a typed check + an optional model-based review loop.

## Pipeline

```
input ──▶ 1.Digest ──▶ 2.Script/Storyboard ──▶ 3.TTS ──▶ 4.Manim codegen ──▶ 5.Render ──▶ 6.AV QC ──▶ 7.Assemble
topic / chapter /         beats: narration            per-segment        per-scene        segment     per beat:     concat +
paper / repo              lines + visual intent       MiMo audio +       code (skills     mp4s        sync check,   BGM, titles,
                          (+timing budget)            measured dur       + critic loop)               subtitles     outro
```

### Stage 1 — Digest
Input → structured knowledge object (claims, formulas, figures, code snippets, audience level).
Sources: topic string / markdown chapter / arXiv PDF / git repo (README + key modules).

### Stage 2 — Script & storyboard
LLM writes a **beat sheet**: ordered beats `{narration_text, visual_intent, est_duration}`.
Narration style modeled on 3b1b: second person, questions first, "say the hard thing twice".
Storyboard attaches per-beat animation specs; shared asset manifest (icons, images) like
Code2Video's `D_asset` cache for cross-scene consistency.

### Stage 3 — TTS per beat (the sync mechanism)
- One MiMo-TTS call per beat (`assistant` content = narration text; `user` content = style
  directive — lecturer tone, pacing hints).
- Measure each segment's true duration via ffprobe.
- Emit a **timing manifest**: `{beat_id: {audio_file, duration, subtitle cues}}`.
- If a beat must fit a fixed window (rare), regenerate with a slower/faster style directive;
  otherwise the animation budget is set *from* the audio, not vice-versa — sync by construction.

### Stage 4 — Manim codegen
- Per-scene ManimCE code generated by the agent guided by the **skill pack**
  (style tokens: palette, fonts, camera presets; idioms: TransformMatchingTex,
  Indicate/Circumscribe beats, 3b1b layout conventions; the visual-anchor grid for placement).
- `NarratedScene` (a `VoiceoverScene` subclass, `anytomanim.voiceover`): each beat wraps
  its animations in `with self.voiceover(beat="b03") as tracker:` and paces `run_time`s
  off `tracker.duration` / `get_remaining_duration()`. `MiMoService(beats_file=...)`
  replays the wav measured in stage 3 (manim-voiceover itself has no `audio_file=`
  input), so the planned durations are the rendered audio.
- Debug loop: render errors → traceback-guided repair; then the LOOK step:
  `anytomanim preview` = per-beat contact sheet (mid + end frame) + the audit
  NarratedScene writes (leftovers by beat of first appearance, text overlap / size /
  off-frame, narration overrun, frozen time). The host agent reads both and fixes.
  (Planned: a VLM critic on the same sheet using the 6×6 anchor-grid prompt.)

### Stage 5 — Render
`manim render` per scene at target quality; parallelizable per scene.

### Stage 6 — AV QC
- Structural: every beat's animation duration ≥ audio duration − ε; scene boundaries land
  on sentence ends.
- Acoustic: optional whisperX/aeneas forced alignment of final audio vs script →
  flag drift/missing narration.
- Visual: VLM judge pass (layout/occlusion/legibility) → feed back to stage 4.

### Stage 7 — Assemble
ffmpeg concat per-scene MP4s (audio already embedded by manim-voiceover), optional BGM bed
under voice (−18 dB ducking), title card, chapter markers, outro. Emit SRT + manifest.

## Packaging layers

| Layer | Artifact | Consumer |
|---|---|---|
| L0 CLI | `anytomanim <input> [-o out.mp4]` | humans, CI |
| L1 Skill | `SKILL.md` + scripts + style lib (progressive disclosure) | any agent (Devin, Claude Code, pi) |
| L2 Harness | pi extension / MCP server exposing `plan`, `tts`, `render`, `qc` tools | agentic workflows, our own eval farm |

## Key decisions (defaults, open for discussion)

- **ManimCE over ManimGL** — docs, stability, voiceover plugin, community; 3b1b style is
  reproducible in CE (manim_skill's manimgl notes cover GL-only idioms if ever needed).
- **Skill-first over harness-first** — the skill pack is the lowest-dependency artifact
  and the most portable; harness integration (pi extension, MCP) wraps the same tools.
- **MiMo-TTS primary**, behind a `SpeechService` interface so Edge-TTS/Azure/recording
  drop in unchanged.
- **English-first**, architecture language-agnostic (MiMo handles zh/en).
